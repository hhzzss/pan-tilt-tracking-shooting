# 用 FlyMcu 烧录双舵机往返测试

可以使用现有的 `E:\嵌入式\FlyMcu2188.exe`。已检查这个程序包含 `STM32F40xx_41xx` 器件支持，与 C30D 的 STM32F407VET6 对应。Keil负责把源代码编译成HEX，FlyMcu通过串口把同一份HEX写入芯片；本次不用ST-Link，也不用修改固件。

## 接口与准备

1. 先关闭两只舵机的电源，C30D按原接线正常供电；K230不用接入本次测试。下载新程序会覆盖板上原应用，需要保留时先备份。
2. 用可传数据的USB线，将电脑接到C30D标有 **串口1／一键下载** 的Type-C。不要接串口3，也不要接5V输出Type-C。
3. 在设备管理器“端口(COM和LPT)”里确认这一接口对应的CH9102串口号。可插拔USB观察哪个COM消失/出现；若没有串口，先检查数据线与CH9102驱动。
4. 关闭占用该COM的串口助手，再打开桌面的FlyMcu2188快捷方式。

## FlyMcu 设置与下载

| 项目 | 设置 |
|---|---|
| 芯片/协议（若有选择） | STM32，使用芯片自带串口BootLoader |
| 端口 | 上一步确认的串口1对应COM |
| 波特率 | 先用115200；通信不稳定时降到57600 |
| 联机控制下拉框 | **DTR的低电平复位,RTS高电平进BootLoader** |
| 程序文件 | `..\outputs\firmware\05_dual_sweep.hex` |
| 校验 | 勾选 |
| 编程后执行 | 勾选 |
| 编程到FLASH时写选项字节 | 不勾选 |

联机控制选项按C30D的CH9102自动下载电路选择：DTR经Q5控制NRST，RTS经Q6控制BOOT0。FlyMcu选项中的高低电平采用其RS232控制线表述，不要直接当成CH9102引脚TTL电平去改接线。本板使用板载自动下载电路，不需要额外连接DTR、RTS或短接BOOT0。依据为随交付保存的C30D原理图镜像第2页“串口1一键下载电路”；不同硬件修订若改变该电路，需重新核对。

1. 先点 **读器件信息(R)**，确认成功识别STM32；软件可能显示 `STM32F40xx_41xx` / 器件ID `0x413`，不一定显示完整的F407VET6名称。
2. 成功后确认选择的是 **05_dual_sweep.hex**，再点 **开始编程(P)**。HEX自带Flash地址，不需转换成BIN或手动偏移地址。
3. 等待日志显示编程及校验成功。不要点“清除芯片(Z)”尝试修复普通连接问题，也不需要修改读保护或选项字节。
4. 若提示无法联机，先核对COM、USB接口、串口占用、主板供电及上面的联机选项；此时保留错误日志排查，不随意更换BOOT接线。

## 上板观察

确认云台中位附近有活动空间，接通舵机电源。程序上电/复位先输出1500μs保持2秒，再让底座PC6和俯仰PC7同时缓慢往返，脉宽为 `1500→1600→1400→1600…μs`。端点间约4秒，完整往返约8秒；两轴幅度不同，因为底座是270°舵机，俯仰是180°舵机。

如果程序已运行一段时间再给舵机供电，2秒等待可能已过去；想重新观察启动过程，可在机构有空间时按C30D复位。启动的1500μs指令直接回中，不保证机械慢速回中。测试持续运行，关闭舵机电源才能停止动作，复位会重新开始。

双轴往返程序、编译和主机测试已通过；本说明没有实际打开串口、下载芯片或验证实物动作。FlyMcu通信和实际运动以本次上板结果为准。
