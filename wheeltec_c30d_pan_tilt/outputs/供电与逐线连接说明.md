# C30D＋K230＋两只位置舵机：接线与上电

适用：普通绿色四驱 C30D（STM32F407VET6）＋DshanPI CanMV V3＋S20F 270°/180°位置舵机。依据轮趣官方商品图及用户本地K230原理图；详细来源见 [资料核对](reference/资料核对.md)。如果实物为C30D SE或其他K230载板，本文接口位置不能直接照搬。

## 1. 各部分电压与电源容量

| 部件 | 已核实的输入规格 | 本项目供电选择 |
|---|---|---|
| C30D整板 | 官方6～17V；主控芯片内部为3.3V逻辑 | 12V接板上蓝色螺丝端子；官方未给整板本体最大耗流，不能编造“必须几A” |
| DshanPI CanMV V3 | USB1的5V入口 | 稳压5V、3A容量支路；3A为含摄像头的工程建议，不是已查到的官方最低电流 |
| S20F270°底座 | 5～6.5V；堵转1.8A@5V/只 | 与俯仰共用外部5V、5A容量支路 |
| S20F180°俯仰 | 同上 | 两只按3.6A堵转电流估算，5A留余量；1.8A数据只对应5V |

电源的“A”是可提供的容量，设备按负载取电。不要按空载80mA给舵机选电源。用户的“S20系列”若不是当前官方S20F，应以实物子型号额定值为准。

**可以共用一个上游电源。**推荐一个稳压12V/5A适配器（60W容量示例），分三支：

```text
12V/5A上游 + ─┬─→ C30D 蓝色电源输入端子 +
              ├─→ 降压模块A → 稳压5V/3A → K230 USB1供电口
              └─→ 降压模块B → 稳压5V/5A → 两只舵机红线
上游负极 ────────→ 三个支路的地；K230 GND、C30D GND、舵机地共同连接
```

下游两个5V支路共40W额定容量，加上降压损耗和C30D本体，12V/5A可作为本项目不带电机的起点。带额外电机、屏幕等时要重新核算功率。降压模块须能连续带载并承受舵机启动冲击；先调到5V再插设备。舵机电源与K230电源分别走线回到供电分配点，不让舵机电流经过K230排针/杜邦线。舵机支路可在靠近舵机处加470～1000μF电解并联0.1μF陶瓷，注意极性。

C30D宣传的独立5V5A输出是对外供电能力，不能据此断言所有舵机排针也能承担5A，更不能把K230与双舵机同时挂上就保证稳定。这里选择外部舵机电源，便于排除掉电重启。板上标注对树莓派供电的Type-C是**输出口**，不要当C30D输入口。C30D整板不要接到3.3V针上供电；12V绝不能接K230或舵机。

K230的USB1还承担电脑连接/IDE调试。独立运行时接上述5V电源；USB1接电脑调试时不能再用普通Y线把另一5V电源并进去。若电脑口供电稳定，可先由电脑供电调试，保存板端程序后断开电脑、换外部5V电源运行。需要同时保留USB数据与外部供电时，使用明确隔离电脑VBUS、保留数据和共地的合格供电/数据分离方案；不能把两个5V输出直接并联。

## 2. K230和C30D：只要两根信号相关线

**当前固件改用背面“预留IO”表中的PA3，不再使用蓝牙PD6。必须先重新烧录PA3版。**见 [PA3接线与测试](PA3串口接线与测试.md) / [实物丝印标注](C30D_PA3接线位置.png)。按用户照片方向，PA3位于表左列、PA6下方/PA2上方，与PC3同一行；可选GND位于表右列、与5V同一行且在PA7/PD15上一行。图圈的是丝印名称，接其对应排针，不接丝印附近任意焊点。

K230上 J6 是两只 Type-C 之间的四芯UART接口，按原理图针号识别，见 [位置图](K230_UART2接口位置.png) / [原理图](K230_UART2接口原理图.png)。J6的两个固定焊脚不算信号针；不能把IO44误认为“排针第44脚”。

| K230 DshanPI CanMV V3 | C30D端 | 是否接/作用 |
|---|---|---|
| J6-2，TX，IO44 | 预留IO排针 **PA3** | 必接：K230发送→STM32 USART2接收（AF7） |
| J6-4，GND | 预留IO排针 **GND** | 必接：信号参考共地 |
| J6-3，RX，IO45 | 无 | 留空；当前USART2只启用接收，不回传 |
| J6-1，3.3V | 无 | 留空 |
| 无 | C30D的5V、3V3、PA2 | 留空；两板之间仅接TX→PA3和GND→GND |

两端都是3.3V TTL逻辑，直接交叉TX→RX；不用RS232或RS485转换板，不把排针TTL接到电脑RS232口。PA3不得同时接其他信号源。本项目不用C30D“串口3”Type-C和K230做USB互连；也不用K230调试UART0作为跟踪通道。原PD6线拔除，PA2不配置为TX，PC6/PC7舵机信号保持原接法。

## 3. 两只舵机：信号接板，红线接外部5V

先看 [C30D官方接口图](reference/C30D_官方接口图.jpg)：电机A/B/C/D口在下侧时，六路舵机接口位于板上方，官方称“预留拓展IO，含6路舵机接口和航模遥控接口”。按板上 **C6、C7、5V、G/GND** 丝印确认，不按照片的上/下方向猜。

| 导线 | 接到哪里 |
|---|---|
| 底座270°信号：官方S20F为白线 | C30D舵机接口 **C6 / PC6** 信号针（镜像原理图J1 pin1） |
| 底座270°红线 | 外部舵机电源 **+5V** |
| 底座270°黑线 | 外部舵机电源 **GND**，并与C30D GND共地 |
| 俯仰180°信号：官方S20F为橙线 | C30D舵机接口 **C7 / PC7** 信号针（镜像原理图J2 pin1） |
| 俯仰180°红线 | 同一个外部舵机电源 **+5V** |
| 俯仰180°棕线 | 外部舵机电源 **GND**，并与C30D GND共地 |
| C30D两路舵机接口的中间电源针 | **不接**，不要让外部5V反灌板载舵机电源 |

三芯舵机插头不能保持原样全部插上，再额外并外电源。用转接/分线线束，把红线独立引出；信号与地按丝印连接。线色来自官方S20F图，若实物线色不同，以信号/正/负定义为准。剩余四路舵机接口不用，六路接口也不要同时接航模接收机来驱动相同信号。

这里的270°/180°是舵机内部行程。当前跟随程序开放底座60～210°，总计150°，相对正前左右各75°；俯仰仍为75～105°。1500μs分别约等于内部135°/90°；支架的物理正前/水平应在回中后安装舵盘对齐。扩大后的底座范围需在实物上检查支架与线材是否有干涉。

## 4. 电脑、日志与下载器

- 日志：电脑USB→C30D标注 **串口1、一键下载** 的Type-C。安装CH9102驱动后，串口终端选对应COM，115200 / 8位 / 无校验 / 1停止位 / 无流控。该口输出日志，K230数据从PA3进入。
- C30D仍按上述蓝色端子供电；不要把串口USB当成已确认足够的整板/舵机电源。若供电时电脑口或板子出现异常，立即断电检查接线。
- 下载推荐ST-Link：SWDIO→板上DIO/PA13；SWCLK→CLK/PA14；GND→GND；带VTref的正规下载器VTref→板上3.3V参考。板子独立供电。廉价ST-Link上标“3.3V”的针可能是输出，不能当VTref直接与带电板并接，按该下载器定义接；NRST可选接板复位。

## 5. 第一次上电顺序

1. 断电接线，电机使能开关保持关闭，电机口留空；移除舵盘负载或先松开机构，扶住俯仰部件。
2. 万用表先量C30D输入正负、K230入口5V、舵机5V；核对地已连、舵机红线未接板中间针。
3. 先不接舵机电源，打开C30D主电源开关（电机使能仍关闭），烧录阶段1固件并接日志口；再只接底座舵机电源，验证1500μs回中。阶段2再单测俯仰。
4. 单舵机正常后用阶段3串口监视，最后阶段4接入视觉。**每次复位/重新烧录，位置舵机可能直接回中；启动回中不受跟随软件限速约束。**先回中再装正舵盘，不在任意姿态带负载直接刷跟随固件。

详细固件操作见 [编译烧录与分步验证](编译烧录与分步验证.md)。
