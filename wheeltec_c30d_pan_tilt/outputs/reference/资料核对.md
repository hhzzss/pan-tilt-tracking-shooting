# 资料来源和适用范围

核对日期：2026-10-20。已通过用户登录的 Edge 访问轮趣旗舰店，读取商品选项、详情图片；没有购买或给商家发消息。

1. [C30D 官方商品](https://detail.tmall.com/item.htm?id=665902328666)：选择普通绿色 C30D ROS 底层主控（四驱）。主控 STM32F407VET6，6～17V 输入；有独立对外 5V5A 输出、串口1下载、SWD，支持 MDK/标准库/HAL。不要混用 C30D SE、C10B 图片。本工程只对应绿色四电机接口 C30D。
2. [S20F 官方商品](https://detail.tmall.com/item.htm?id=645346572889)：180°/270°位置型，5～6.5V，1.8A@5V 堵转电流/只，500～2500μs 全行程。参数表脚注明确 270°型号行程270°。用户称 S20 系列，本文参数适用于该店当前 S20F；若实物标签是其他 S20 子型号，应先按该型号额定值核对。360°连续型不适用角度控制。
3. C30D 原理图来自 [Emailmail/c30d_hal 镜像](https://github.com/Emailmail/c30d_hal/tree/HEAD/00_Document)，不是从官方商品下载的原理图。原文件名含 V2.2，PDF 页脚却写 REV23.0 / 2025-03-20 / WHEELTEC。只用作与官方照片丝印的交叉核对；不把它当作所有历史板次通用资料。
4. 镜像页1：PD6=USART2 RX、PD5=USART2 TX，蓝牙排针5V/GND/PD6/PD5；PA9/PA10经CH9102对应串口1。页2：J1 PC6、J2 PC7，分别为信号/5V5/GND。页3：舵机电源与对外Type-C电源是不同支路，不能用“对外5V5A”反推舵机排针额定总电流。5V5是网络名，本文不将其解释成已测得5.5V。
5. K230 使用用户本地 `K230_DshanPI-CanMV-V3-SCH.pdf` 与位号图核对，J6 pin1=3.3V、pin2=TX IO44、pin3=RX IO45、pin4=GND。供电为USB1的5V入口。[官方入门](https://eai.100ask.net/CanaanK230/part1/DshanPICanMVV3quickstart/) / [UART文档](https://eai.100ask.net/CanaanK230/part9/UartGuide)。其他 K230 载板不能照搬 J6 编号。

6. 2026-10-21串口接收迁移：用户实物背面预留IO丝印包含PA3，镜像原理图页1也将PA3引到扩展排针；板次的排针排数不同，不沿用镜像H2针号。[ST官方STM32F405/407数据手册](https://www.st.com/resource/en/datasheet/stm32f407ve.pdf) 表7列出PA3支持USART2_RX，表9的PA3行/AF7列确认复用号。当前固件只配置PA3接收，PA2不作发送；旧蓝牙PD6接法停止使用。[实物丝印标注](../C30D_PA3接线位置.png)。
