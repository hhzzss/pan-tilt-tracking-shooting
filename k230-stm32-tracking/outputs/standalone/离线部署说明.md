# K230＋C30D 电池独立运行

`main.py` 是当前 sabo 玩偶检测＋C30D 串口跟随程序的离线入口，默认 `enable_preview = False`。它不初始化 IDE 虚拟显示、不采集通道0预览、不绘制检测框；仍由 CSI0 摄像头通道2采集640×480图像，使用原320×320模型推理，并从IO44发送115200 8N1的跟随帧。无目标发送丢失帧，发送最高20Hz，实际取决于推理速度。

## SD卡部署

1. 停止IDE运行的程序，关闭设备电源，先备份SD卡原有的 `main.py`。保留现有CanMV固件和 `boot.py`。
2. 用读卡器将本目录 `main.py` 复制到SD卡根目录；也可以在CanMV IDE中打开该文件，保存到开发板的 `/sdcard/main.py`。单击IDE运行不会自动把电脑文件保存到SD卡。
3. 保留已经跑通的模型文件。若尚未复制，将 `../../..\model\mp_deployment_source` 整个文件夹复制到SD卡的 `model` 文件夹下。
4. SD卡应包含以下文件；不要把main.py放进model文件夹，也不要保存为main.py.txt。

```text
SD卡根目录（K230中对应 /sdcard）
├─ main.py
└─ model/
   └─ mp_deployment_source/
      ├─ best_AnchorBaseDet_can2_5_s_20261020171350.kmodel
      └─ deploy_config.json
```

当前程序直接使用代码中已匹配的模型参数，不在运行时读取deploy_config.json；保留该文件便于核对。libs、nncase_runtime、aicube、ulab等使用现有固件中的模块，无需复制整套电脑实验文件夹。

5. 安全弹出SD卡并装回K230。断开电脑USB，换外部稳定5V供电后重新上电；现有CanMV启动流程应执行 `/sdcard/main.py`。模型与摄像头初始化需要时间，之后才开始跟随。首次运行应在现场观察。
6. 若不能自启，重新连接IDE检查板端 `/sdcard/main.py` 和模型实际路径、读取启动异常；不要先更换已跑通的固件。调试预览可将 `enable_preview` 改为True并接IDE，独立部署时恢复False。

## C30D

已经烧录并验证过跟随程序的C30D，不因换成电池供电而需要重新烧录。Flash掉电保留，上电/复位后自动运行。只有要更新控制逻辑、速度、方向或限位时，才需要重新编译并烧录；电脑上的HEX更新不会自动更新板内程序。

当前跟随固件位于 `../../../wheeltec_c30d_pan_tilt\outputs\firmware\04_tracking_PA3.hex`。UART接线保持K230 IO44 → C30D PA3、GND共地，舵机信号保持PC6/PC7。

## 锂电池供电

按现有硬件资料，C30D整板输入为6～17V，K230 USB1入口为5V，所核对S20F舵机为5～6.5V。实际S20子型号以实物额定值为准。

若使用带保护的3串锂离子电池组（标称11.1V、满电12.6V），可使用以下分配；这只是3串电池接法，其他串数须重新核对电压和转换模块。

```text
3串锂电池组 → 总开关 → 分配点
                       ├─ C30D蓝色电源端子（核对正负）
                       ├─ 降压A：稳定5V，建议3A容量 → K230 USB1
                       └─ 降压B：稳定5V，建议5A容量 → 两只舵机电源
电池负极、两路降压负极、K230、C30D、舵机地共同连接
```

3A/5A是支路容量建议，电池、保护板、开关、导线及降压模块也应能承担实际总负载和舵机启动电流。先测好降压输出再接设备。锂电池原电压不能直接接K230的5V入口或舵机；舵机电流不要经过K230供电线。两路降压5V正输出不要互相并联。原接线中舵机红线已独立供电，继续保持，不与C30D舵机排针电源并接。

电脑USB调试供电与外部5V之间采用断开后换接，不能用普通Y线并联两个电源。C30D上电会先让两只舵机回中；K230随后启动检测，C30D在没有有效目标帧时保持指令位置。
