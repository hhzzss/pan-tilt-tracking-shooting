# 项目说明

## 1. 环境与运行方式

项目材料对应 DshanPI CanMV-K230 V3，板端执行 MicroPython/CanMV 程序，电脑使用 CanMV IDE 连接开发板。例程依赖 `media`、`machine`、`libs`、`nncase_runtime`、`ulab`、`aicube` 等板端模块。固件与板端资源应从原资料来源获取，本仓库不捆绑安装包或完整系统镜像。

原始入门步骤见 `CanMV_V3.0/04_MicroPython例程源码/redme.txt`。先使用简单的 LED、串口或摄像头例程确认连接，再运行 AI 检测。

## 2. 例程分类

`CanMV_V3.0/04_MicroPython例程源码/` 按原目录保留：基础实验、摄像头实验、特征检测、颜色处理、条形码、AI 视觉、多媒体、网络、AICube 和 CV_Lite 等。例程各自独立，不是一个从根目录执行的 Python 应用。

部分例程需要 `/sdcard/examples/kmodel/`、`/sdcard/examples/utils/` 等厂商配套资源。本仓库没有这些资源的完整集合；遇到文件缺失时，应按例程中的板端路径补齐对应原始资源。

## 3. sabo 模型配置

`model/mp_deployment_source/deploy_config.json` 的当前内容：

| 参数 | 值 |
| --- | --- |
| 芯片 | k230 |
| 模型类型 | AnchorBaseDet |
| 输入 | 320 × 320 |
| 类别 | sabo，1 类 |
| 置信度阈值 | 0.4 |
| NMS 阈值 | 0.5 |
| 配置标注的 nncase 版本 | 2.11.0 |

这些是文件中的配置值，并不代表本次已完成板端兼容性验证。

### 原始图片 / 视频部署入口

`model/det_image.py` 和 `model/det_video.py` 读取 `/sdcard/mp_deployment_source/deploy_config.json`。将仓库内 `model/mp_deployment_source/` 的内容复制到该板端目录，JSON 和 KModel 放在一起。单图入口还需要自行准备 `/sdcard/test.jpg`；测试照片及历史检测结果未纳入仓库。

`det_video.py` 当前设置 `display_mode = "lt9611"`、采集尺寸 1280 × 720，并使用 `PipeLine`。使用其他显示或摄像头连接时，需根据实际硬件和原平台 API 调整，不能把它直接当作已经适配全部硬件的入口。

### 已修改的检测 / 串口跟踪入口

当前 `CanMV_V3.0/04_MicroPython例程源码/06_AI视觉实验/01_人形处理/01-1_人形检测/person_detection.py` 已用于 sabo 模型、CSI0 摄像头、IDE 预览和串口跟踪。该入口的模型位置是：

```text
/sdcard/model/mp_deployment_source/best_AnchorBaseDet_can2_5_s_20261020171350.kmodel
```

注意：该目录比原始部署入口多一层 `model/`。按实际运行的脚本放置文件，不要混淆两个入口。跟踪脚本将模型相关参数写在代码里，并非在运行时读取 JSON；更换模型时须同步检查配置、预处理和后处理。

## 4. SDK 编译指南的边界

仓库保留了原 `SDK编译指南.md`，用于解释本地完整源码包的构建流程。该指南描述的是另外提供的完整 EdgeOS SDK；其 `canmv_k230.tar.gz` 未上传。因此，不能在本仓库根目录直接执行指南中的 `make` 命令来构建固件。

## 5. 验证范围

本次发布整理会校验文件复制前后的 SHA-256、Python 语法及 JSON 可解析性。Python 语法检查不执行板端导入，也不能代替实机检测、串口收发、舵机运动或继电器安全验证。
